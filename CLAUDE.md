# Колбочки

Казуальная головоломка «сортировка шариков» для платформы Яндекс Игры. Аудитория — все возрасты, монетизация — реклама Яндекса.

## Структура

- `source/index.html` — вся игра в одном файле: стили, разметка, JS. Без фреймворков и сборщиков.
- `source/build_yandex.py` — сборка для Яндекса: `python build_yandex.py` (из папки `source`).
  Подключает `/sdk.js` (относительный путь обязателен для архива из консоли), заменяет Google Fonts на локальные шрифты из `source/fonts`, выключает отладочный `window.__kolb`.
- `build/kolbochki-yandex.zip` — архив для загрузки в консоль. `build/yandex-build/` — то же в распакованном виде, для локальной проверки в браузере.
- `source/index.html` не имеет `<!doctype>`/`<head>`: это фрагмент, обёртку добавляет сборка. Для проверки в браузере открывай `build/yandex-build/index.html`.

## Правила игры

- В колбе 4 шарика (`CAP`). Шарик можно положить в любую колбу, где есть место (колбы работают как буфер). Цель — в каждой колбе один цвет.
- Уровни генерируются детерминированно из номера (`genLevel(l)`, сид `l*7919+13`), каждый проверяется решателем на проходимость.
- Цветов: 2 на 1-м уровне, далее растёт до 10 (`levelColors`). Пустых колб: 2 до 3-го уровня, потом 1 (`levelEmpties`).
- Особые уровни (`levelKind`): «спящие» шарики с 8-го (l % 3 === 2) — скрыт цвет всех, кроме верхнего; «ледяная колба» с 12-го (l % 4 === 0) — колба заблокирована, пока не собрана любая другая.
- Звёзды: `par` = кратчайшее решение из нескольких прогонов A*; 3★ если ходов ≤ par, 2★ если ≤ ceil(par*1.4)+1.

## Код (ключевые части index.html)

- `solve()` — DFS-решатель (быстро находит любое решение, используется для проверки уровней и обучения).
- `astar()` + `hScore()` — взвешенный A* для коротких решений (звёзды и подсказка).
- `Work` — тяжёлые расчёты (par, подсказка) в Web Worker из blob, с фолбэком на основной поток. Функции, которые попадают в воркер, должны быть самодостаточными (используют только CAP, runLen, isDone, isSolved).
- `Ads` — обёртка над `ysdk.adv`: `fullscreen()` между уровнями (с 4-го), `rewarded()` за награду. Без SDK показывает демо-заглушку. Во время рекламы звук глушится и вызывается `GameplayAPI.stop()` — это требования модерации.
- `Cloud` — облачное сохранение через `player.setData/getData`, при конфликте выигрывает больший `max`, затем свежий `ts`. Локально дублируется в `localStorage` (`kolbochki-v2`).
- `Rating` — лидерборд с техническим именем `levels` (создаётся в консоли Яндекса). Поддерживает новый `ysdk.leaderboards` и старый `getLeaderboards()`.
- Состояние игрока `S` (схема в `DEFAULT`): уровень, max, монеты, звёзды по уровням, скины/фоны, прогресс разблокировки за рекламу, бонус дня, задания дня, просмотренные обучалки.
- Мета: бонус дня (7 дней, `DAILY`), задания дня (`TASK_POOL`, 3 в день, выбор по дате), магазин скинов (`SKINS`, `BGS`; разблокировка монетами или 3 рекламами), сезонные Тыковки/Хэллоуин до 7 ноября (`seasonOn`).
- Скины сделаны CSS-классом `skin-<id>` на `#board`, декорации (`.dec`) уже есть в разметке каждого шарика.

## Требования Яндекс Игр, которые нельзя ломать

- `LoadingAPI.ready()` вызывается после загрузки, `GameplayAPI.start/stop` — при начале/паузе геймплея.
- Звук выключается при показе рекламы и при уходе со вкладки.
- Полноэкранная реклама только в паузах (между уровнями), частоту ограничивает платформа.
- Никаких JS-ошибок в консоли.

## Проверка после правок

1. Синтаксис скрипта: вытащить `<script>` из index.html и прогнать `node --check`.
2. Пересобрать: `python source/build_yandex.py`, открыть `build/yandex-build/index.html`, пройти 2–3 уровня, проверить консоль.
3. Проверить на ширине телефона (~375px).
