Колбочки — игра-сортировка шариков для Яндекс Игр

source\index.html        — исходник игры (одна страница: стили, логика, реклама, сохранения)
source\build_yandex.py   — сборка архива для Яндекса: python build_yandex.py
source\fonts\            — шрифты Unbounded и Nunito, кладутся в архив
build\kolbochki-yandex.zip — готовый архив для загрузки в консоль Яндекс Игр
build\yandex-build\       — то же, что в архиве, в распакованном виде

Перед публикацией в консоли:
1. Подключить монетизацию (вкладка «Реклама»).
2. Создать лидерборд с техническим именем levels.
3. Загрузить kolbochki-yandex.zip, проверить через ?debug-mode=16.

Проверить игру локально: открыть build\yandex-build\index.html в браузере.
Без Яндекса реклама показывается заглушками, а прогресс хранится в браузере.
